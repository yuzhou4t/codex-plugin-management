# Build Web Apps Plugin

Focused workflows for explicit visual frontend design, specialized Stripe platform work, and Supabase/Postgres.

## Skills

- `frontend-app-builder`
- `stripe-best-practices`
- `supabase-postgres-best-practices`

## Purpose

Use `frontend-app-builder` only for an explicit greenfield visual surface or substantial redesign. Image generation is optional and should be used only when it resolves a real visual need.

Use `stripe-best-practices` for Connect, Treasury, legacy migration, and other advanced non-Vercel Stripe work. Standard Vercel payment flows belong to the installed Vercel payments skill.

Use `supabase-postgres-best-practices` for Postgres schema, query, security, connection, and operational guidance.

React, Next.js, shadcn/ui, and general frontend verification are intentionally not duplicated here; use the current official specialist skills.
