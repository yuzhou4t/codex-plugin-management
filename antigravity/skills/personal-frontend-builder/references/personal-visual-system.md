# 个人软件视觉参考

只在用户要统一个人产品风格，或新产品尚无已确认视觉规范时使用。已有产品或品牌规范优先；颜色数值可为对比度和平台渲染微调。

| 语义 | 浅色 | 深色 |
| --- | --- | --- |
| 背景 | `#F6FBFF` → `#E6F2FF` | `#06111F` → `#0B1F38` |
| 主表面 | `rgba(255,255,255,.94)` | `rgba(14,31,54,.94)` |
| 主文字 | `#172033` | `#E8EFFF` |
| 次文字 | `#59697D` | `#91A1C2` |
| 主操作／选中 | `#407DF5` | `#66A6FF` |
| 细边框 | `rgba(179,209,245,.48)` | `rgba(102,166,255,.32)` |

- 整体保持安静、紧凑、清晰：白蓝浅色、海军蓝深色、原生中文字体、少量蓝色主操作。
- 使用语义 token，统一导航、卡片、表单和按钮；不要在业务页面到处散落原始色值。
- 一处任务区只保留一个明显主操作。卡片用细分隔和适度留白形成层级，避免深层套卡、大片灰色表单和大量玻璃模糊。
- 图标、按钮高度和文字基线保持一致；长中文标签及中英文混合名称要完整可读。
- 重要状态同时用文字或图标表达，不能只靠颜色。深色模式需保留表面层次与可读对比。
- 动效用于反馈或状态转换，尊重减少动态效果设置。桌面实测宽、窄窗口；有移动端时实测滚动、触控和遮挡。

本参考源自仓库 `skills/apply-personal-app-design-system/` 的自维护设计系统。需要更细的控件规格时再查原资料，不在每次前端任务中加载整份设计手册。
