# 代码驱动宣传片制作与分镜设计

先判断用户需要**直接制作成片**，还是**整理可执行的视频制作提示词**，再确定是先探索多个创意方向还是直接进入制作。

- **直接制片模式**：读懂项目材料与素材后，走“事实锚定 → 创意提案/选型 → `cueSheet` 与代码实现 → 多阶段视觉与成片核验”，直接产出 `1920×1080` 带音轨 MP4、关键帧与设计说明。
- **提示词整理模式**：读取项目真实要点后，按 [提示词模板](references/prompt-template.md) 输出一份结构化中文任务说明，填入已核实的项目数据与素材路径，不擅自开始重度渲染。

## 1. 事实与品牌资产锚定（Zero-Hallucination Brief）

动手写分镜或组件前，先通读项目 `README`、核心前端页面代码、宣发单页（PDF / 海报）以及品牌素材目录（如 Logo、SVG、吉祥物原稿），抽出 4 项硬输入：

1. **核心定位**：一句话说明白产品给谁解决什么真实卡点。
2. **痛点与机制对应**：真实痛点是什么、工作流/产品如何把每一步落地或闭环。
3. **硬事实与不可编造数据**：真实的观测样本量、回归/实验结果、开源指标、活动节点（日期/周期/资助额/主办支持单位）。**严禁编造任何数字、用户评价或虚假功能**；项目单页或需求迭代更新后，必须同步清洗代码里的旧日期和旧卡片文案。
4. **品牌视觉资产**：已有配色、字体栈、Logo 文件与可用插画；若目标与核心约束（如时长、用途：复赛答辩 vs 招新发布）无法从材料确定，只提问一轮关键澄清。

## 2. 开放式创意探索与参考母版（母版只是起点，禁止拘泥）

现有产品的视觉规范和品牌资产优先级最高。没有既定规范或尚未锁定视频方向时，先基于过往实战沉淀出两套**参考母版**作为锚点，同时**绝不把创意限制在这两套里**：

### 经典参考母版
- **母版 A · Apple Editorial（理性克制 / 复赛答辩与产品发布）**
  - 质感：象牙白/深炭底大留白 + 单一高辨识度品牌强调色 + 大字报核心论点。
  - 结构：多条痛点快闪收束成一句话 → 品牌揭幕 → 光标串联真实工作台全流程（输入 → 点击 → 校验 → 产出）→ 少而硬的真实数据定格 → 一句话价值收尾。
- **母版 B · Kinetic Studio（高燃卡点 / 招新宣发与多赛道展示）**
  - 质感：黑 / 白 / 高饱和强调色按 BPM 强对比切换。
  - 结构：节奏重拍踩点 → 痛点撕裂/重构 → 2→4→9 多格 Bento 生态爆发 → 多方向微型领域工作室（Domain Studio）轮播 → 0.25–0.35s 静音蓄力后强势落版。

### 多版本发散要求（与用户共创方向时必做）
当用户希望讨论风格、比对思路或看看不同版本效果时：
1. **跳出默认母版**：结合产品气质主动发掘 **2–4 种不同风格路线** 让用户挑选或混搭——例如：
   - **数据纪实 / 交互式论文风**：像会动的学术图谱或实证报告一样展开论证与数据检验；
   - **3D 空间器物漫游 / 工程拆解风**：用三维透视网格、结构爆炸图或设备仪表展示硬件与底层架构；
   - **印刷版式 / Riso 胶片拼贴风**：强网格线、矢量版画质感、时间轴切片与章节序号；
   - **Live Terminal / 架构蓝图叙事**：从 CLI、代码 Diff、数据流拓扑切入产品实战。
2. **先出小样比对，再进全片**：可按需先渲染 3–4 张不同方向的关键帧概念图，或极简短片段预览，确认节拍、密度与美术调性后，再投入全量镜头的编码实现。

## 3. 标准 6 步制片流程与核心红线

### Step 1 · 引擎与动画确定性
- 需要复杂 React 状态机、动态数据图表、多阶段自适应网格和脚本化音画同步时，优先使用 **Remotion**；偏轻量 DOM / CSS / GSAP 动效或项目已配置 HyperFrames 时，可衔接 HyperFrames。
- 所有视觉变化（位移、缩放、线条描边、打字机字符数、进度条、波形高度）**必须严格由帧号确定**（`interpolate` / `spring` / 三角函数）。**禁用不可控的 CSS `transition`、`@keyframes` 与 `Math.random()`**。

### Step 2 · 五幕压缩叙事与 `cueSheet` 单一时间轴
- 30–60 秒黄金配比：**Hook / 痛点收束（~15%） → 破局 / 品牌揭幕（~10%） → 核心工作台交互或主题实演（~45%） → 规模或真实数据证明（~18%） → 蓄力静音与品牌落版（~12%）**。
- **痛点压缩原则**：超过 3 条痛点时不要逐条慢念，可用快速闪现叠层并收束为 1 句核心判断。
- **可读性最小停留**：冲击短词 `≥ 0.8s`；信息卡或代码交互段 `≥ 1.3–2.5s`；高潮或落版前预留 `0.25–0.35s` 纯静音黑场蓄力；结尾连续重拍给够视觉阅读余韵。
- 建立单一时间轴文件（如 `src/cueSheet.json`），所有分镜起止帧号和音效触发点只读这一份配置。

### Step 3 · 代码重建界面与“一秒可辨”原则
- **严禁静态图硬拼**：不要用多张 AI 静态图加简单缩放凑成宣传片，导致动态僵硬且关键文案与排版无法精确控制。
- **严禁无语义装饰几何**：不要把空表格、随机转圈弧线或漂浮圆点直接当产品配图。
- **工作台交互闭环**：产品实演必须用代码重建**输入 → 光标移动与点击态 → 校验/计算过程 → 结果与指标浮现**完整链路，绝不用静态截图贴图糊弄。
- **领域工作室（Domain Studio）**：展示抽象行业或赛道方向时，统一包装进有明确顶栏、主题徽标和实时动画微界面的终端卡片（例如：流水线、三轨 NLE 剪辑条、机械臂运动学、K 线盘口、化学分子构象、古籍 OCR 与推演网络），让观众 **1 秒内看懂“画的是哪行、为什么能动”**。
- **多阶段容器避坑红线**：遇到 `2 格 → 4 格 → 9 格` 这类网格展开时，严禁在单行高容器中把内层设为 `height: 100% + justifyContent: 'space-between'`——这会把少量卡片垂直撕成上下孤岛。应为低格数阶段限制合理行高并居中排布，同时按格数缩放内层图表与间距。
- **前景叠加安全区**：若角落有卡通/吉祥物或弹窗叠加层，底层卡片必须在该象限预留无核心文字与关键曲线的安全留白。

### Step 4 · 可商用配乐与音效精准卡点
- 通过程序合成音轨（如 Node 生成 48kHz 立体声 WAV）或可商用授权素材构建配乐，严格读取 `cueSheet.json` 的帧号触发底鼓、键盘敲击、鼠标点击、whoosh 转场与静音停顿。
- 导出或混音阶段做好峰值控制，实测音频峰值压在 `-1.0 dB` 左右，确保响度饱满且零削波。

### Step 5 · 可选增强：真实吉祥物 / 插画透明视频混合
- 仅在需要把文档/PDF/品牌原画里的复杂角色忠实保留并动起来时，按需读取 [真实吉祥物透明视频管线](references/hybrid-mascot-pipeline.md)。纯 UI 与纯图形宣传片默认不需要触发 I2V 模型，以保持轻量化和文字可控性。

### Step 6 · 全跃迁帧检验与成片硬验收
渲染全片前与成片后，必须依次完成以下全部检查：

1. **静态类型与构建检查**：`tsc --noEmit`（或等价构建检查）零报错。
2. **全阶段视觉抽检（不能只看最终帧！）**：
   - 单独渲染并打开检查**每一个阶段及过渡态**：触发操作前/后（如 `DIFF` 点击前与通过后）、多格布局的**每一种格数**（如 `2` 格、`4` 格、`9` 格各自一帧）、每一个行业方向卡、多行中英文标题与对齐、以及前景叠加安全区。
   - 检查音轨进度条是否溢出容器、标注文字是否压到曲线、旧文案是否清理干净；发现任何一帧瑕玷必须修复后二次复检该帧。
3. **成片封装要求**：导出 `1920×1080`、`30fps` 或 `60fps`、`h264`、`yuv420p`、`aac 48kHz` 立体声，开启 `+faststart` 以便网页/答辩即时加载。
4. **编码后 MP4 实测验收**：对最终输出 MP4 执行 `ffprobe`、`ffmpeg -af volumedetect` 并实际抽取 1–2 帧成片截图查验；交付物包含**带音轨 MP4 + 关键帧截图 + 简要设计思路**。
