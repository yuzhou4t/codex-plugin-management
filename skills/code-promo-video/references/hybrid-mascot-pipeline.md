# 真实吉祥物 / 插画透明视频混合管线（按需启用）

仅当项目中存在**高细节品牌原画（如 PDF / 矢量导出卡通形象、手绘吉祥物）**，且纯 CSS / SVG 骨骼动画会失真时启用本流程。常规纯代码宣传片无需启用。

## 1. 无损提取与角色补全

- **PDF 原图无损提取**：优先使用 `pdfimages -png` 分离图像与软遮罩（smask），再用 `ffmpeg` 的 `alphamerge` 合成真正的 `rgba` PNG（而非直接截取带背景色的页面截图）。
- **缺失角色风格对齐**：若有新增赛道缺少原画，以现有真迹 RGBA 角色作为参考图，使用图像编辑/生成模型仅针对缺失角色按同一网点/版画/插画风格生成在纯绿背景（`#00FF00`）上，严禁整张重新生成从而破坏已有角色的原本笔触。

## 2. 防绿边溢出预处理（关键技巧）

直接在 `#00FF00` 上对细黑描边或暖橙色毛发做绿幕抠像，边缘极易泛绿或被啃噬。送入 I2V 生成动画前，先用图像处理对原角色 `alpha` 通道做一次 `3px` 形态学膨胀（`dilation`），在原图外围垫出一圈 `2–3px` 与画面主体协调的中性边缘（如奶油白 `#F4ECD8` 贴纸轮廓），再叠加到 `#00FF00` 纯绿底图上。

## 3. 生成短动效与并发控制

- 凭据统一走环境变量（绝不写入仓库、脚本或 Git 历史）；根据所用 SDK/端点要求核对接口版本。
- 提示词明确要求：**保留原图构图、笔触与人物服饰细节；保持 `#00FF00` 纯绿背景与静态镜头；仅在原地做小幅度自然动作（如挥手、点头、轻按按钮、火箭小幅喷火）**。
- 批量提交多个角色请求时，如遇平台瞬时限流（`429 RESOURCE_EXHAUSTED`），改用低并发或逐一串行重试，避免并发打满配额。

## 4. 透明通道抠像与主画面合层

- **WebM Alpha 转码**：对生成的绿色背景短视频做两段式绿幕抠像与溢色抑制，导出支持透明通道的 VP9 WebM：
  ```bash
  ffmpeg -y -i raw_green.mp4 \
    -vf "chromakey=0x00FF00:0.24:0.08,despill=type=green:mix=0.5,format=yuva420p" \
    -c:v libvpx-vp9 -pix_fmt yuva420p -auto-alt-ref 0 -crf 24 -b:v 0 -an output_alpha.webm
  ```
- **独立短视频交付（可选）**：若需单独发布 5 秒吉祥物短视频，可在纯深色或品牌底色上另压一版 `640×640` `h264 yuv420p +faststart` MP4。
- **主宣传片合成**：
  - 使用 `<OffthreadVideo src={...} transparent muted startFrom={N} />`（适当跳过首尾半秒渐入/静止帧，让角色一出场就处于灵动姿态）。
  - **2.5D 遮挡安全区**：前景吉祥物固定在右下/左下角时，必须与底层的领域工作室（Domain Studio）或尾帧底部落版文案错开安全间距，并分别在深底（`#000`）、浅底（`#FFF`）与彩色底下渲染静态帧检查是否存在绿边残留或黑框。
