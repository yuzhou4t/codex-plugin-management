## Default Topic Map

Use these themes when the user asks broadly for recent AI papers:

- reasoning models, verifiers, chain-of-thought control, latent-space reasoning, and test-time scaling
- agents, tool use, web agents, code agents, multi-agent planning, and long-horizon interaction
- multimodal models, VLMs, visual grounding, OCR, PDF/document understanding, image/video quality evaluation
- long context, sparse attention, KV cache efficiency, tokenization alternatives, byte/patch-level models
- world models, robotics, autonomous driving, LiDAR, Gaussian splatting, 3D/4D reconstruction, video generation and evaluation
- AI for science, protein/chemistry/materials models, mechanistic interpretability, formal verification, verified code generation
- safety, hallucination, alignment resistance, fairness, unlearning, provenance, training-data tracing, AI-assisted peer review

## Search Notes

- Use official venue pages first for exact year, acceptance category, awards, and PDFs.
- Use DBLP to enumerate a venue/year or verify bibliographic metadata, then click through to primary sources.
- Use arXiv when the official page lacks a PDF or the paper has a newer public version; label arXiv versions separately from venue versions.
- For journals, check issue pages and article pages because publication year, online-first dates, volume, and DOI can differ.
- For Chinese summaries, explain the research problem, method idea, main contribution, and why the paper is worth reading.
