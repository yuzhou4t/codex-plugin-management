# 演示发布检查清单

围绕本次要展示的流程和发布目标选择检查项，复用已经有效的验证。检查发现阻塞时继续完成独立部分，明确哪些内容可以展示、哪些尚未验证。检查本身不授权公开推送、部署、开放端口或外发链接；沿用用户已有授权。

## 数字与结果来源

- 对照实际数据、查询或运行记录核对界面、幻灯片、视频和 README 中的重要数字。多处引用同一指标时维护一致的口径；存在差异就标明样本、时间或筛选条件。
- 区分预生成、现场生成、历史结果和人工整理。预生成材料记录来源与版本，录屏可以作故障备用，但回放不能表述为现场运行。
- 对依赖网络或模型的演示，按需要准备可明确标识的回放或离线样例；真实服务未运行时，不把备用样例当作功能验收。

## 公开内容与凭据

- 检查本次发布差异和拟公开产物，确认没有密钥、认证状态、私有数据或内部敏感信息。发现泄露证据时，再定点核查受影响版本和发布范围。
- 按内容和项目约定判断文档是否适合公开，保留正常的项目说明、架构、SPEC 和协作指令；仅对确认不应公开的文件处理跟踪或发布范围，保留本机原件。改写已发布历史另看授权。
- 密钥方案遵循项目架构：服务端密钥保留在服务端；只有产品明确采用访客自带密钥时才使用该方案，并核对存储、转发和日志。通过 HTTPS 传输真实凭据；HTTP 环境用无凭据样例演示，不发送真实密钥。

## 涉及部署时

- 核对当前服务、端口归属和目标域名，保护共享主机上的其他服务。部署复用项目已有流程，明确构建版本、服务路径和恢复方法。
- 需要调整防火墙、安全组或账号权限时，先准备具体变更；已有授权覆盖的操作直接执行，新增权限变更再由用户决定。
- 从独立于部署主机的访问路径验证公网首页、实际使用的深层链接及主要 API 流程。本机回环或内网检查只证明对应范围；缺少外部验证条件时保留这个未验证项。

## 演示前收敛与交付

- 临近演示优先修复会阻断演示路径的问题，保留一个可用回退版本。用户要求冻结或项目发布流程需要时再建立 tag；普通改动不要求额外 tag 或固定冻结时限。
- 修改后重走受影响的演示路径。报告实际运行或部署的版本、检查结果、备用材料的性质和剩余阻塞；准备完成与公网可用分别按证据说明。
